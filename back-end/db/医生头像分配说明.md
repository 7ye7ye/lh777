# 医生头像图标分配说明

## 头像路径分配规则

根据科室类型，为医生分配不同的头像图标：

### 1. 临床科室医生 - `/static/doctor.svg`
适用于：内科、外科、口腔科、护理科
- 内科系统：呼吸内科、心内科、消化内科、神经内科、内分泌科
- 外科系统：骨科、皮肤科、普通外科、外伤处理
- 口腔科：口腔内科、口腔外科、口腔修复
- 护理科：门诊护理、住院护理、社区护理

### 2. 体检检查科室 - `/static/check.svg`
适用于：体检科、B超室
- 体检科：常规体检、入职体检、专项体检
- B超室：腹部B超、妇科B超、心脏彩超

### 3. 预防保健科室 - `/static/images/health-bg.png`
适用于：预防保健科
- 预防保健科：儿童保健、妇女保健、老年人保健

### 4. 行政科室 - `/static/info_message.png`
适用于：公疗报销
- 公疗报销：门诊报销、住院报销、慢病报销

## 执行顺序

1. **执行 `init_department.sql`** - 创建科室表
2. **执行 `init_doctor.sql`** - 为前10个科室添加医生（已有头像）
3. **执行 `完善科室和医生数据.sql`** - 为所有科室补充医生（已有头像）
4. **执行 `完善所有医生头像.sql`** - 更新已有医生的头像（如有需要）

## 验证SQL

```sql
-- 检查每个科室的医生数量和头像设置
SELECT 
    d.dept_id AS '科室ID',
    d.dept_name AS '科室名称',
    COUNT(do.doctor_id) AS '医生数量',
    GROUP_CONCAT(DISTINCT do.avatar) AS '使用的头像'
FROM department d
LEFT JOIN doctor do ON d.dept_id = do.dept_id AND do.is_active = 1
WHERE d.dept_level = 2
GROUP BY d.dept_id, d.dept_name
ORDER BY d.dept_id;

-- 检查没有头像的医生
SELECT 
    do.doctor_id,
    do.doctor_name,
    d.dept_name,
    do.avatar
FROM doctor do
LEFT JOIN department d ON do.dept_id = d.dept_id
WHERE do.is_active = 1 
  AND (do.avatar IS NULL OR do.avatar = '')
ORDER BY d.dept_id, do.doctor_id;
```

## 前端显示

前端会根据 `doctor.avatar` 字段显示头像，如果为空则使用默认头像：
- `doctors.vue`: 默认使用 `/static/doctor.svg`
- `department-detail.vue`: 默认使用 `/static/images/default-avatar.png`

所有医生现在都已设置了合适的头像图标！
