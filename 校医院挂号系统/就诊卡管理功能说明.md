## API 接口列表

已在 `api/patient.ts` 中定义以下接口：

### 就诊卡相关
- `getCard(data: { userId: number })` - 获取就诊卡信息
- `createCard(data: CreateCardRequest)` - 创建就诊卡
- `updateCard(data: UpdateCardRequest)` - 更新就诊卡
- `unbindCard(data: { userId: number; patientId: number })` - 解绑就诊卡
- `rechargeCard(data: { amount: number })` - 就诊卡充值
- `getCardHistory()` - 获取就诊卡历史记录

### 就诊人相关
- `getPatientList(data: { userId: number })` - 获取就诊人列表
- `addPatient(data: CreateCardRequest)` - 添加就诊人
- `updatePatient(data: UpdateCardRequest)` - 更新就诊人信息
- `deletePatient(data: { userId: number; patientId: number })` - 删除就诊人

### 健康档案相关
- `getHealthProfile(data: { patientId: number })` - 获取健康档案
- `updateHealthProfile(data: HealthProfileRequest)` - 更新健康档案

## 核心功能实现

### 1. 一个就诊人对应一个就诊卡
- 每个就诊人（patient）都有唯一的 `patientId`
- 创建就诊卡即创建就诊人
- 在 mypatient.vue 中展示所有就诊人列表
- 点击就诊人可查看详细就诊卡信息

### 2. 页面刷新机制
- 使用 `onShow` 生命周期钩子
- 从创建/修改页面返回时自动刷新数据
- 确保数据实时同步

### 3. 数据脱敏
- 身份证号：保留前3位和后4位，中间用星号替换
- 手机号：保留前3位和后4位，中间用星号替换

### 4. 二维码和条形码生成
- 使用 `uni_modules/Sansnn-uQRCode` 组件
- 条形码显示在就诊卡顶部
- 二维码显示在就诊卡中间和就诊人卡片右侧
- 二维码内容为门诊号或患者ID

## 使用流程

### 创建就诊卡流程
1. 用户从 mycard 页面点击"立即创建"或从 mypatient 页面点击"添加就诊人"
2. 跳转到 create-card 页面
3. 填写完整的就诊卡信息
4. 提交创建
5. 创建成功后返回上一页
6. mycard 或 mypatient 页面自动刷新显示新数据

### 修改就诊卡流程
1. 在 mycard 页面点击"修改个人信息"
2. 跳转到 modify-info 页面，携带当前就诊卡信息
3. 修改需要更新的字段
4. 输入验证码
5. 提交修改
6. 修改成功后返回，mycard 页面自动刷新

### 解绑就诊卡流程
1. 在 mycard 页面点击"解绑电子就诊卡"
2. 弹出确认对话框
3. 确认解绑
4. 调用解绑 API
5. 解绑成功后清空数据并返回上一页

### 健康档案流程
1. 在 modify-info 页面点击"健康档案"
2. 跳转到 health-profile 页面
3. 填写或修改健康档案信息
4. 点击保存
5. 保存成功后返回

## 注意事项

### 1. 需要添加的图片资源
健康档案页面需要一张健康相关的插图，建议放置在：
```
static/images/health-bg.png
```
尺寸建议：600rpx × 400rpx

如果没有图片，可以：
- 使用默认占位符
- 或者从插画网站下载合适的健康主题插图

### 2. 后端 API 适配
所有 API 接口都已定义，后端需要实现：
- `/patient/cardInfo` - 获取就诊卡
- `/patient/create` - 创建就诊卡/就诊人
- `/patient/update` - 更新就诊卡/就诊人
- `/patient/unbind` - 解绑就诊卡
- `/patient/list` - 获取就诊人列表
- `/patient/delete` - 删除就诊人
- `/patient/health/get` - 获取健康档案
- `/patient/health/update` - 更新健康档案

### 3. 数据字段映射

#### 就诊卡/就诊人字段
- `patientId` - 患者ID（主键）
- `userId` - 用户ID（关联用户表）
- `patientName` - 患者姓名
- `idType` - 证件类型
- `idCard` - 证件号码
- `gender` - 性别
- `birthDate` - 出生日期
- `nation` - 民族
- `nationality` - 国籍
- `region` - 所在地区
- `detailedAddress` - 详细地址
- `phone` - 手机号
- `patientType` - 患者类型（1-学生/2-教师/3-职工）
- `studentId` - 学号（学生类型时必填）
- `staffId` - 工号（教师/职工类型时必填）
- `emergencyContact` - 紧急联系人
- `emergencyPhone` - 紧急联系人电话
- `outpatientNumber` - 门诊号（系统生成）

#### 健康档案字段
- `patientId` - 患者ID
- `height` - 身高
- `weight` - 体重
- `bloodType` - 血型
- `maritalStatus` - 婚姻状况
- `fertilityStatus` - 生育情况
- `currentIllness` - 现病史
- `pastHistory` - 既往史
- `familyHistory` - 家族史
- `allergyHistory` - 过敏史
