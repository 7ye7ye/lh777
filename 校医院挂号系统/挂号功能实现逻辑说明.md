# 小程序挂号功能实现逻辑说明

## 📋 功能概览

小程序挂号功能实现了从选择医生、预约时段、支付到创建挂号记录的完整流程，支持正常挂号、候补队列、重复挂号检查等功能。

---

## 🔄 完整流程

```
选择医生 → 预约页面 → 选择挂号类型/日期/时段 → 确认预约 → 支付页面 → 支付成功 → 创建挂号记录 → 消息通知
```

## 📱 前端页面结构

### 1. **预约页面** (`subpkg/hospital/appointment.vue`)

#### 功能职责
- 显示医生基本信息（头像、姓名、职称、擅长）
- 选择挂号类型（普通号/专家号等）
- 选择预约日期（7天内）
- 选择预约时段（上午/下午/晚上）
- 显示号源剩余情况
- 处理候补队列逻辑

#### 关键数据
```javascript
// 页面状态
doctor: { doctorId, doctorName, title, specialty, avatar }
department: { deptId, deptName }
registrationTypes: [] // 挂号类型列表
selectedType: { typeId, typeName, priceOriginal }
appointmentDate: '2025-11-20' // 预约日期
schedules: [] // 排班列表
selectedSchedule: { schedule_id, time_slot, available_quota }
selectedSlot: 'morning' | 'afternoon' | 'evening'
```

#### 核心逻辑

**1. 页面加载 (`onLoad`)**
```javascript
// 1. 获取路由参数（医生ID、科室ID等）
// 2. 加载挂号类型列表
await loadRegistrationTypes()
// 3. 设置默认挂号类型
selectedType.value = registrationTypes.value[0]
// 4. 默认选中今天日期
appointmentDate.value = today
// 5. 加载医生排班（7天内）
await loadSchedules(doctorId, today, 7)
```

**2. 加载排班信息 (`loadSchedules`)**
```javascript
// API调用：GET /applet/registration/schedules
// 参数：{ doctorId, startDate, days }
// 返回：排班列表，包含 schedule_date, time_slot, available_quota 等
const res = await getDoctorSchedules(doctorId, startDate, days)
```

**3. 计算时段状态 (`slotStatus` 计算属性)**
```javascript
// 根据选中的日期和挂号类型，过滤匹配的排班
// 计算每个时段（上午/下午/晚上）的：
// - exists: 是否有排班
// - available: 是否有剩余号源
// - remaining: 剩余号源数
```

**4. 选择时段 (`selectTimeSlot`)**
```javascript
// 情况1：无排班 → 提示"该时段暂无排班"
// 情况2：有排班但已满 → 弹出候补选项
// 情况3：有剩余号源 → 直接选中，更新 selectedSchedule
```

**5. 候补队列处理**
```javascript
// 当号源已满时，用户可选择加入候补
// 构建挂号记录（status: 0 表示候补）
const record = {
  scheduleId,
  patientId,
  doctorId,
  typeId,
  status: 0, // 候补状态
  ...
}
// 调用 createRegistration(record, patientId, true)
// 第三个参数 joinWaitingQueue = true
```

**6. 确认预约 (`confirmAppointment`)**
```javascript
// 1. 检查是否完整选择（挂号类型、日期、时段）
// 2. 获取患者ID（确保有就诊卡）
const patientId = await ensurePatientId()
// 3. 检查重复挂号
const isDuplicate = await checkDuplicateBySchedule(patientId, scheduleId)
// 4. 如果通过，跳转到支付页面
uni.navigateTo({
  url: `/subpkg/hospital/payment?dept=...&doctor=...&time=...&scheduleId=...`
})
```

### 2. **支付页面** (`subpkg/hospital/payment.vue`)

#### 功能职责
- 显示挂号信息摘要（科室、医生、时间、费用）
- 选择支付方式（微信支付/支付宝/医保卡）

#### 关键数据
```javascript
// 从路由参数获取

doctor: '李医生'
time: '2025-11-20 上午'
fee: 20 // 挂号费
doctorId: 16
typeId: 1
scheduleId: 123
```

#### 核心逻辑

**1. 页面加载 (`onMounted`)**
```javascript
// 从路由参数解析信息
const options = getCurrentPages()[pages.length - 1].options
dept.value = decodeURIComponent(options.dept)
doctor.value = decodeURIComponent(options.doctor)
time.value = decodeURIComponent(options.time)
doctorId.value = Number(options.doctorId)
typeId.value = Number(options.typeId)
scheduleId.value = Number(options.scheduleId)
```

**2. 支付处理 (`onPay`)**
```javascript
// 1. 检查是否选择支付方式
// 2. 显示支付加载提示
uni.showLoading({ title: '正在支付...' })

// 3. 模拟支付（实际项目中应调用真实支付接口）
setTimeout(async () => {
  uni.hideLoading()
  uni.showToast({ title: '支付成功！', icon: 'success' })
  
  // 4. 获取患者ID
  const patientId = await ensurePatientId()
  
  // 5. 构建挂号记录对象
  const record = {
    scheduleId: scheduleId.value,
    patientId,
    doctorId: doctorId.value,
    typeId: typeId.value,
    registrationNo: generateRegistrationNo(), // 生成挂号单号

    status: 1, // 已预约
    priceOriginal: fee.value,
    actualPrice: fee.value,
    isAdd: 0 // 正常号
  }
  
  // 6. 调用创建挂号API
  await createRegistration(record, patientId, false)
  
  // 7. 跳转首页
  uni.switchTab({ url: '/pages/home/home' })
}, 2000)
```

**3. 工具函数**
```javascript
// 生成挂号单号：YYYYMMDD + doctorId + 随机3位
function generateRegistrationNo() {
  const date = new Date()
  const y = date.getFullYear()
  const m = (date.getMonth() + 1).toString().padStart(2, '0')
  const d = date.getDate().toString().padStart(2, '0')
  const random = Math.floor(Math.random() * 1000).toString().padStart(3, '0')
  return `${y}${m}${d}${doctorId.value}${random}`
}

// 格式化时间：YYYY-MM-DD HH:mm:ss
function formatLocalDateTime(date) {
  const pad = (n) => n.toString().padStart(2, '0')
  return `${date.getFullYear()}-${pad(date.getMonth()+1)}-${pad(date.getDate())} ${pad(date.getHours())}:${pad(date.getMinutes())}:${pad(date.getSeconds())}`
}
```

## 🔌 API接口定义

### 文件：`api/registration.ts`

#### 1. **获取挂号类型**
```typescript
export const getRegistrationTypes = async () => {
  return request.get('/types')
}
// GET /applet/registration/types
```

#### 2. **获取医生排班**
```typescript
export const getDoctorSchedules = async (
  doctorId: number, 
  startDate: string, 
  days = 7
) => {
  return request.get('/schedules', { doctorId, startDate, days })
}
// GET /applet/registration/schedules?doctorId=16&startDate=2025-11-20&days=7
```

#### 3. **创建挂号记录**
```typescript
export const createRegistration = async (
  record: Record<string, any>,
  patientId: number,
  joinWaitingQueue = false
) => {
  const url = `/create?patientId=${patientId}&joinWaitingQueue=${joinWaitingQueue}`
  return request.post(url, record)
}
// POST /applet/registration/create?patientId=1&joinWaitingQueue=false
// Body: { scheduleId, doctorId, typeId, registrationNo, registerTime, status, priceOriginal, actualPrice, isAdd }
```

#### 4. **检查重复挂号**
```typescript
export const checkDuplicateBySchedule = async (
  patientId: number, 
  scheduleId: number
) => {
  return request.get(
    `/checkDuplicateBySchedule?patientId=${patientId}&scheduleId=${scheduleId}`
  )
}
// GET /applet/registration/checkDuplicateBySchedule?patientId=1&scheduleId=123
```

#### 5. **加入候补队列**
```typescript
export const addWaitingQueue = async (data: {
  scheduleId: number
  patientId: number
  recordId?: number
}) => {
  return request.post('/addWaitingQueue', data)
}
```

## 🗄️ 数据流转

### 前端 → 后端传递的数据

#### 创建挂号请求体
```javascript
{
  scheduleId: 123,              // 排班ID（必填）
  patientId: 1,                 // 患者ID（URL参数，后端会重新设置）
  doctorId: 16,                 // 医生ID（可选，后端会从排班表查询）
  typeId: 1,                    // 挂号类型ID（必填）
  registrationNo: "20251120161001",  // 挂号单号（可选，后端可生成）
  registerTime: "2025-11-20 16:10:01",  // 挂号时间（可选，后端使用服务器时间）
  status: 1,                    // 状态：1-已预约，0-候补（可选，后端会设置）
  priceOriginal: 50.00,         // 原价（可选，后端会从挂号类型表查询）
  actualPrice: 50.00,           // 实付价（可选，后端会根据患者类型重新计算）
  isAdd: 0                      // 是否加号：0-正常号，1-加号（必填）
}
```

### 后端处理流程

1. **数据验证**：检查必填字段
2. **查询排班信息**：从 `doctor_schedule` 表获取医生ID、科室ID、已用号源数
3. **检查重复挂号**：查询 `registration_record` 表，防止同一患者重复预约同一排班
4. **查询挂号类型**：从 `registration_type` 表获取价格信息
5. **检查号源**：比较 `used_quota` 和 `daily_quota`
6. **查询患者信息**：从 `patient` 表获取患者类型（学生/教职工）
7. **计算实际价格**：
   - 学生：使用 `student_price`
   - 教职工：使用 `staff_price`
   - 其他：使用 `price_original`
8. **生成挂号单号**：如果前端未传递，后端生成（格式：`YYYYMMDD + 科室ID + 序号`）
9. **插入挂号记录**：写入 `registration_record` 表
10. **更新排班**：`used_quota = used_quota + 1`
11. **创建消息**：在 `message_log` 表创建"预约挂号成功提醒"消息

## 🔑 关键功能点

### 1. **就诊卡检查**

在预约和支付前，都需要确保用户已创建就诊卡：

```javascript
// 工具函数：确保有就诊卡
const ensurePatientId = async () => {
  // 1. 尝试从本地获取
  const info = await ensurePatientCard()
  if (info?.patientId) {
    return info.patientId
  }
  
  // 2. 如果没有，提示用户创建
  uni.showModal({
    title: '未找到就诊卡',
    content: '请先创建并绑定就诊卡后再进行挂号操作',
    confirmText: '去创建',
    success: (res) => {
      if (res.confirm) {
        uni.navigateTo({
          url: '/subpkg/profile/personal/create-card'
        })
      }
    }
  })
  return null
}
```

### 2. **重复挂号检查**

在确认预约时，调用接口检查是否已预约过同一排班：

```javascript
const isDuplicate = await checkDuplicateBySchedule(patientId, scheduleId)
if (isDuplicate) {
  uni.showToast({
    title: '您已预约过该时段，请勿重复挂号',
    icon: 'none'
  })
  return
}
```

### 3. **号源状态计算**

通过计算属性实时计算每个时段的可用状态：

```javascript
const slotStatus = computed(() => {
  // 1. 过滤匹配日期和挂号类型的排班
  const daySchedules = schedules.value.filter(s => {
    const dateStr = s.schedule_date?.substring(0, 10)
    const typeId = s.type_id
    return dateStr === appointmentDate.value && 
           Number(typeId) === Number(selectedType.value.typeId)
  })
  
  // 2. 按时段分组，计算剩余号源
  daySchedules.forEach(schedule => {
    const slotKey = timeSlotReverseMap[schedule.time_slot]
    const remaining = schedule.available_quota ?? 0
    result[slotKey] = {
      exists: true,
      available: remaining > 0,
      remaining
    }
  })
  
  return result
})
```

### 4. **候补队列处理**

当号源已满时，用户可选择加入候补：

```javascript
// 1. 构建候补挂号记录（status: 0）
const record = {
  scheduleId,
  patientId,
  status: 0, // 候补状态
  ...
}

// 2. 调用创建接口，joinWaitingQueue = true
const res = await createRegistration(record, patientId, true)

// 3. 后端会：
//    - 创建挂号记录（status=0）
//    - 加入候补队列（waiting_rank 自动分配）
//    - 不更新排班的 used_quota
```

### 5. **挂号单号生成**

前端生成规则（后端也可生成）：

## 📊 数据库表关系

```
hos_user (用户表)
  └── user_id (主键)

patient (患者表)
  ├── patient_id (主键)
  └── user_id (外键 → hos_user.user_id)

registration_record (挂号记录表)
  ├── record_id (主键)
  ├── patient_id (外键 → patient.patient_id)
  ├── schedule_id (外键 → doctor_schedule.schedule_id)
  ├── doctor_id (外键 → doctor.doctor_id)
  └── type_id (外键 → registration_type.type_id)

doctor_schedule (排班表)
  ├── schedule_id (主键)
  ├── doctor_id (外键 → doctor.doctor_id)
  ├── dept_id (外键 → department.dept_id)
  ├── schedule_date (排班日期)
  ├── time_slot (时段：1-上午，2-下午，3-晚上)
  ├── max_quota (最大号源数)
  └── used_quota (已用号源数)

registration_type (挂号类型表)
  ├── type_id (主键)
  ├── type_name (类型名称)
  ├── price_original (原价)
  ├── student_price (学生价)
  └── staff_price (教职工价)

message_log (消息表)
  ├── message_id (主键)
  ├── user_id (外键 → hos_user.user_id)
  ├── appointment_id (关联 → registration_record.record_id)
  └── message_type (消息类型：APPOINTMENT_SUCCESS)
```

## ⚠️ 注意事项

1. **就诊卡前置条件**：挂号前必须创建就诊卡，否则会提示跳转到创建页面
2. **重复挂号检查**：同一患者不能重复预约同一排班（status != 3）
3. **号源实时性**：排班信息需要实时查询，避免号源超售
4. **候补队列**：号源已满时可选择候补，状态为 `status: 0`
5. **价格计算**：后端会根据患者类型重新计算实际价格，前端传递的价格仅供参考
6. **消息通知**：挂号成功后会自动创建消息，用户可在消息中心查看

## 📝 完整示例

### 正常挂号流程
```
1. 用户选择医生 → 进入预约页面
2. 选择挂号类型（普通号/专家号）
3. 选择预约日期（今天或未来6天）
4. 选择时段（上午/下午/晚上）
5. 点击"确认预约" → 检查重复挂号
6. 跳转支付页面 → 选择支付方式
7. 点击"立即支付" → 模拟支付成功
8. 调用 createRegistration API
9. 后端创建挂号记录、更新排班、创建消息
10. 跳转首页，用户可在消息中心查看挂号成功通知
```

### 候补队列流程
```
1. 用户选择时段，发现号源已满
2. 点击时段 → 弹出"加入候补"选项
3. 用户确认 → 调用 createRegistration(record, patientId, true)
4. 后端创建挂号记录（status: 0）
5. 加入候补队列，分配 waiting_rank
6. 提示"已加入候补队列"
```
