# 体检功能模块使用说明

## 模块概述

本次开发完成了完整的体检服务功能模块，包含1个主页面和5个子功能页面，提供了从预约到报告查询的全流程体检服务。

## 页面结构

### 1. 体检服务主页 (`pages/physical-exam/physical-exam.vue`)

**功能特点：**
- 渐变色顶部设计，展示"体检服务"品牌形象
- 顶部Banner展示体检中心基本信息
- 主功能区采用卡片式布局，包含5大功能入口：
  - 个检预约（紫色渐变）
  - 团检预约（粉红渐变）
  - 体检报告（蓝色渐变，带未读数量徽章）
  - 体检订单（橙色渐变，带未处理订单徽章）
  - 体检中心（淡彩渐变）
- 快捷服务区：套餐选择、体检时间、注意事项、电话咨询
- 温馨提示卡片

**访问路径：**
- 从首页点击"体检"标签下的任一菜单项
- 直接访问：`/pages/physical-exam/physical-exam`

### 2. 个检预约页 (`subpkg/physical-exam/individual-booking.vue`)

**功能特点：**
- 完整的个人体检预约流程
- 4种套餐选择（基础、教职工、全面、高端）
- 日期选择器（支持未来30天预约，排除周日）
- 时间段选择（显示剩余名额）
- 体检人信息表单（姓名、性别、手机号、身份证、备注）
- 实时计算总价
- 表单验证（手机号、身份证格式验证）

**导航栏：**紫色背景，白色文字

### 3. 团检预约页 (`subpkg/physical-exam/group-booking.vue`)

**功能特点：**
- 粉红色渐变顶部Banner
- 团检信息录入（单位名称、人数、期望日期）
- 联系人信息（联系人、电话、邮箱）
- 套餐选择（显示9折优惠，50人以上8.5折）
- 特殊需求备注（500字）
- 6步团检流程展示
- 温馨提示列表
- 底部双按钮（电话咨询 + 提交申请）

**导航栏：**粉红色背景，白色文字

### 4. 体检报告页 (`subpkg/physical-exam/exam-report.vue`)

**功能特点：**
- 蓝色渐变顶部搜索栏
- 筛选标签（全部、个检、团检、有异常）
- 报告卡片展示：
  - 姓名、日期、体检类型
  - 报告状态（已出报告/检查中）
  - 异常标识
  - 下载、分享功能
- 空状态提示（含"立即预约体检"按钮）
- 温馨提示卡片

**导航栏：**蓝色背景，白色文字

### 5. 体检订单页 (`subpkg/physical-exam/exam-orders.vue`)

**功能特点：**
- 顶部标签页（全部、待支付、待体检、已完成、已取消）
- 订单卡片展示：
  - 订单号、状态
  - 套餐、体检人、日期、时间
  - 订单金额
- 多状态操作按钮：
  - 待支付：取消订单、立即支付
  - 待体检：查看详情、改约
  - 已完成：查看报告、再次预约
  - 已取消：删除订单、再次预约
- 空状态提示

**导航栏：**粉红色背景，白色文字

### 6. 体检中心介绍页 (`subpkg/physical-exam/exam-center.vue`)

**功能特点：**
- 顶部大图Banner（叠加紫色渐变遮罩）
- 快捷操作区（个检预约、团检预约、查看报告、电话咨询）
- 中心简介（含数据统计：15+年经验、50000+人次、98%满意度）
- 6大服务特色展示
- 12项体检项目网格展示
- 联系我们（电话、邮箱、地址、工作时间）
- 温馨提示列表
- 底部双按钮（电话咨询 + 立即预约）

**导航栏：**紫色背景，白色文字

## UI设计特点

### 色彩方案
- **个检预约**：紫色渐变 `#667eea → #764ba2`
- **团检预约**：粉红渐变 `#f093fb → #f5576c`
- **体检报告**：蓝色渐变 `#4facfe → #00f2fe`
- **体检订单**：橙粉渐变 `#fa709a → #fee140`
- **体检中心**：紫色渐变 `#667eea → #764ba2`

### 设计元素
1. **卡片式布局**：所有内容区域采用圆角卡片，柔和阴影
2. **渐变色**：大量使用渐变色提升视觉层次
3. **图标emoji**：使用emoji图标，生动友好
4. **状态标识**：不同状态用不同颜色标识
5. **响应式**：适配不同屏幕尺寸
6. **过渡动画**：卡片点击、状态切换有过渡效果

## 交互功能

### 已实现的交互
1. **导航跳转**：所有页面间可正常跳转
2. **日期选择**：弹出选择器选择日期
3. **时间段选择**：多个时间段单选
4. **表单验证**：实时验证手机号、身份证格式
5. **状态切换**：订单状态可切换（待支付→待体检→已完成）
6. **搜索筛选**：报告列表支持搜索和筛选
7. **弹窗提示**：各种操作有相应的提示弹窗
8. **电话拨打**：点击电话咨询可直接拨打
9. **文本复制**：邮箱等信息可复制到剪贴板

### 待对接后端接口的功能
1. 提交预约（个检/团检）
2. 获取体检报告列表
3. 获取订单列表
4. 支付订单
5. 下载报告
6. 分享报告

## 访问方式

### 从首页访问
1. 打开应用首页
2. 点击"体检"标签
3. 选择任一体检服务菜单项

### 直接访问路径
```
主页面：     /pages/physical-exam/physical-exam
个检预约：   /subpkg/physical-exam/individual-booking
团检预约：   /subpkg/physical-exam/group-booking
体检报告：   /subpkg/physical-exam/exam-report
体检订单：   /subpkg/physical-exam/exam-orders
体检中心：   /subpkg/physical-exam/exam-center
```

## 配置说明

所有页面已在 `pages.json` 中完成注册：
- 主页面注册在 `pages` 数组中
- 子页面注册在 `subPackages` 中的 `subpkg/physical-exam/` 子包中
- 每个页面都配置了对应的导航栏颜色和标题

## 模拟数据

当前所有页面使用模拟数据展示，包括：
- 体检套餐（4种）
- 体检报告（4条示例）
- 体检订单（4条示例，不同状态）
- 时间段（4个时间段，不同剩余名额）
