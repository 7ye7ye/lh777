# 创建就诊卡页面使用说明

## 功能概述
创建了一个专门的创建就诊卡页面 `subpkg/profile/personal/create-card.vue`，样式与现有的就诊卡卡片保持一致。

## 页面特点

### 1. 视觉设计
- **渐变背景**：使用与就诊卡相同的蓝色渐变背景
- **毛玻璃效果**：表单容器使用半透明背景和毛玻璃效果
- **一致性**：与现有就诊卡卡片保持相同的视觉风格

### 2. 表单验证
- **姓名验证**：不能为空
- **手机号验证**：格式验证（1开头的11位数字）
- **身份证验证**：18位身份证号格式验证

### 3. 用户体验
- **实时反馈**：输入时提供视觉反馈
- **加载状态**：创建时显示"创建中..."状态
- **成功提示**：创建成功后自动返回上一页

## 使用流程

### 1. 入口
- 从"我的就诊卡"页面点击"立即创建"按钮
- 从未登录状态点击电子就诊卡时的弹窗确认

### 2. 填写信息
- 输入真实姓名
- 输入手机号
- 输入身份证号

### 3. 提交创建
- 点击"立即创建"按钮
- 系统验证表单信息
- 调用API创建就诊卡
- 成功后返回上一页

## 技术实现

### 1. 页面配置
```json
{
  "path": "personal/create-card",
  "style": {
    "navigationBarTitleText": "创建就诊卡"
  }
}
```

### 2. 路由跳转
```javascript
// 跳转到创建就诊卡页面
uniNavigateTo({ url: '/subpkg/profile/personal/create-card' })
```

### 3. API调用
```javascript
const response = await patientApi.createCard(formData.value)
```

## 样式特点

### 1. 卡片样式
- 渐变背景：`linear-gradient(135deg, #3a9cff 0%, #5db7ff 100%)`
- 圆角：`border-radius: 20rpx`
- 阴影：`box-shadow: 0 8rpx 32rpx rgba(58, 156, 255, 0.3)`

### 2. 表单样式
- 半透明背景：`background: rgba(255, 255, 255, 0.15)`
- 毛玻璃效果：`backdrop-filter: blur(10rpx)`
- 输入框样式：白色半透明背景，聚焦时高亮

### 3. 按钮样式
- 主按钮：蓝色背景 `#3a9cff`
- 取消按钮：白色背景，灰色边框
- 禁用状态：灰色背景

## 优势

1. **视觉一致性**：与现有就诊卡卡片保持相同的设计风格
2. **用户体验好**：专门的页面比弹窗更适合填写复杂信息
3. **表单验证完善**：确保用户输入正确的信息
4. **响应式设计**：适配不同屏幕尺寸
5. **易于维护**：独立的页面便于后续功能扩展
